# 项目三：增值服务对客户留存的因果效应评估（A/B 对比 → 分层检验 → 倾向得分匹配）

> 这是三个项目里技术含量最高、最能拉开差距的一个。绝大部分数据分析求职者只会做"组间对比"，
> 而本项目证明了：**表面看到的 31.9 个百分点差异里，约 90% 是选择偏差，真实因果效应只有 3 个百分点。**

## 一、业务背景
运营同学提出："订购了在线安全/技术支持的客户流失率明显更低，应该大力推广增值服务来降低流失。"
但这个结论有个致命问题：**订购增值服务的客户，往往本来就是在网时长更长、忠诚度更高的老客户**——
直接对比会把"老客户本身不容易流失"错误地算成"增值服务的功劳"。

本项目目标：**剥离选择偏差，估计增值服务对留存的真实因果效应**。

## 二、数据来源
IBM Telco Customer Churn，筛选出 5,517 名已开通互联网的客户（未开通者无法订购该服务，属不适用人群）
- 处理组（订购增值服务）：2,964 人
- 对照组（未订购）：2,553 人

## 三、技术栈
Python · SciPy（卡方检验 / T 检验）· Scikit-learn（逻辑回归 / 最近邻匹配）· 倾向得分匹配 PSM · 功效分析

## 四、分析流程（四步递进）

### 第一步：朴素组间对比
| 指标 | 数值 |
|---|---|
| 处理组流失率 | 17.07% |
| 对照组流失率 | 48.96% |
| 差异 | **31.89 个百分点**（95%CI [29.53%, 34.26%]） |
| 卡方统计量 | 641.41（p = 1.65e-141） |
| Cramér's V 效应量 | 0.341 |
| NNT（需服务人数） | 3.14 |

### 第二步：分层分析（排除 Simpson 悖论）
按在网时长分 5 层，逐层做卡方检验，验证结论在各层是否方向一致：

| 在网时长 | 处理组 | 对照组 | 差异 | p 值 |
|---|---|---|---|---|
| 0-6 月 | 41.95% | 68.83% | 26.88pp | 4.0e-15 |
| 7-12 月 | 30.54% | 52.06% | 21.52pp | 1.6e-06 |
| 13-24 月 | 27.17% | 43.93% | 16.75pp | 1.7e-06 |
| 25-48 月 | 17.78% | 35.93% | 18.15pp | 4.9e-13 |
| 49-72 月 | 7.47% | 25.76% | 18.29pp | 1.6e-23 |

各层差异方向一致且均显著 → **不存在 Simpson 悖论**，但加权平均差异降至 **21.34 个百分点**，
说明在网时长确实解释了一部分差异。

### 第三步：逻辑回归控制混淆变量
在 14 个协变量（在网时长、月费、累计消费、合约类型、支付方式、人口属性、其他服务订购数）控制下：
- 处理变量 T 的优势比 **OR = 0.7729**，95%CI [0.7194, 0.8239]（Bootstrap 200 次）

### 第四步：倾向得分匹配（PSM）
- 用逻辑回归估计每个客户的倾向得分，截取共同支持域 [0.046, 0.990]，剩余 5,230 人
- 最近邻 1:1 匹配，caliper = 0.05，成功匹配 **2,741 对**
- **平衡性检验**：15 个协变量中 **13 个** 达到平衡（SMD < 0.1），最大改善是 is_month_to_month（0.947 → 0.028）
- **ATT（匹配后处理效应）= 3.06 个百分点**，95%CI [0.95%, 5.18%]，t = 2.84，**p = 0.0045**

### 功效分析
Cohen's h = 0.698（中等偏大效应量），在 α=0.05、power=0.8 下每组仅需 33 人，实际样本 2,964 / 2,553，**功效充足**。

## 五、核心结论
| 口径 | 效应估计 |
|---|---|
| 朴素组间对比 | 31.89 个百分点 |
| 分层加权 | 21.34 个百分点 |
| 逻辑回归控制后 | OR 0.773 |
| **倾向得分匹配后（ATT）** | **3.06 个百分点** |

**增值服务确实能降低流失，但效果远没有表面看起来那么大——真实效应约为 3 个百分点，
约 90% 的表面差异来自"订购者本身是忠诚老客户"的选择偏差。**

**业务建议**：不要把增值服务当成通用留存手段全员推广（对老客户属于无效投入，NNT 会被严重高估）。
应针对**新客与高流失风险人群**做定向补贴与捆绑，并优先改善光纤用户的体验（该群体流失率 41.9%）。
